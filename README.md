# NomadVPN

NomadVPN ([nomad-vpn.ru](https://nomad-vpn.ru)) is a subscription network service operated since 2022.
Users connect through third-party client apps such as Happ, available for iOS, Android, Windows, macOS and Linux.
Account management and support are available on the website and via the official Telegram bot [@nomadvpn_bot](https://t.me/nomadvpn_bot).

NomadVPN does not publish its own mobile app. It is not affiliated with Android apps named "Nomad VPN" on Google Play or with APK files on Uptodown and similar sites.
